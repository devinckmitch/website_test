# Brand Assets — Royal Zoute Golf Club

Upload hier alle merkidentiteit bestanden. Na het uploaden past de developer het design aan op basis van deze bestanden.

## Mapstructuur

```
brand-assets/
├── styleguide/       ← PDF stijlgids, brandbook
├── logos/            ← Logo bestanden (SVG, PNG, AI)
└── fonts/            ← Lettertypebestanden (.ttf, .otf, .woff, .woff2)
```

## Wat te uploaden

### `styleguide/`
- Stijlgids PDF
- Brandbook PDF
- Kleurenpalet document

### `logos/`
- Club logo (bij voorkeur SVG of hoge resolutie PNG)
- Varianten: kleur / zwart-wit / wit (voor donkere achtergrond)
- Club wapen / crest (indien apart)

### `fonts/`
- Lettertypebestanden in `.woff2` of `.ttf` formaat
- Indien Google Fonts: geef de fontnaam door via GitHub issue of commit message

---

*Na het uploaden van deze bestanden wordt het design systeem aangepast.*
